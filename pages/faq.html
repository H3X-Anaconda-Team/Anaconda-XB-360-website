Frequently asked questions

When will it be released?

There's no date yet. This is a solo project with no funding and no schedule. Star the GitHub repo and you'll be notified the moment a build drops.

Which consoles does it work on?

Any modded Xbox 360 that can run Aurora — RGH, JTAG, or softmod. If Aurora boots, Anaconda XB 360 will too.

Do I need a PC to use it?

No. The whole point is that you install it once and then browse, download, and install content entirely from the console.

Where does the content come from?

Two places:

  • Anaconda's own catalog, hosted on GitHub
  • The Free60 Store (X-Store)

You can also point the store at any other compatible repo from the Settings menu.

Is this piracy?

No. Anaconda XB 360 only hosts and serves homebrew — software that's legal to distribute freely. It does not host commercial game files, leaked content, or anything that requires Xbox Live.

Will I get banned from Xbox Live?

This is a homebrew tool for modded consoles. Running unsigned code on a console connected to Xbox Live has always risked a ban — that's not specific to Anaconda. If you care about Live, keep your console offline.

Can I add my own apps to the catalog?

Yes — open a catalog submission issue with the title, author, description, and a direct download link. Content must be legally distributable homebrew.

Can I run my own private repo?

Yes. Point the store at your own repo.ini from the Settings menu. It'll read any catalog that follows the format documented in CATALOG_FORMAT.md.

Is it open source?

The source is on GitHub under the MIT License. Contributions aren't open right now, but the code is there to read.

Can I help?

Right now, the best thing is to star the repo. If you want to suggest a feature or report a bug, open an issue. Responses may be slow because it's one person.

Why is it taking so long?

Because it's one person doing everything: the C++ app, the catalog, the website, the docs, and the tooling. No team, no funding, no outside help. Progress is slow by necessity.

Why isn't the boot screen GIF on the site?

The boot screen animation is on the GitHub repo README. It's not public yet — it'll be officially released with the first build.
