Install Anaconda XB 360

Not public yet. There's no downloadable build at the moment. This page describes the install process that will apply once version 1.0.0 is released.

Requirements

  • Xbox 360 with RGH, JTAG, or a working softmod
  • Aurora dashboard installed
  • HDD or USB drive with at least 500 MB free
  • Internet connection on the console
  • An FTP client (or a USB drive) to transfer files

Step 1 — Get the .xex

Once released, download AnacondaXB360.xex from the Releases page.

Step 2 — Transfer to your console

Option A — FTP

  1. Connect to your console's FTP server.
  2. Create the folder Hdd:\Apps\AnacondaXB360\.
  3. Upload AnacondaXB360.xex into it.

Option B — USB drive

  1. Format a USB drive as FAT32.
  2. Copy AnacondaXB360.xex into a folder named AnacondaXB360.
  3. Plug the drive into the console.
  4. Use Aurora's file manager to copy the folder to Hdd:\Apps\AnacondaXB360\.

Step 3 — Launch

  1. Open Aurora.
  2. Navigate to your apps list.
  3. Select Anaconda XB 360.

Step 4 — First run

On first launch, Anaconda creates these on your HDD: 

Hdd:\Anaconda\anaconda.cfg
Hdd:\Anaconda\anaconda.log
Hdd:\Anaconda\cache\

The default repo URL is baked in, so the store loads immediately.

Step 5 — Change the repo (optional)

  1. Launch Anaconda XB 360.
  2. Select Settings.
  3. Enter the new repo URL.
  4. Confirm.

The setting is saved to Hdd:\Anaconda\anaconda.cfg.

Uninstalling

  1. Delete Hdd:\Apps\AnacondaXB360\
  2. Delete Hdd:\Anaconda\

Content you installed through the store stays where it was placed.

Troubleshooting

  • App won't launch — re-download the .xex; the file may be corrupt.
  • "Could not reach repository" — test your console's network in Aurora settings.
  • Downloads fail — try a different repo URL in Settings.
  • Extract fails — delete Hdd:\Anaconda\cache\ and retry.

For anything else, check the FAQ or open an issue with your anaconda.log attached.
