What it does

📦

Browse categories

Apps, games, emulators, themes — all in one menu on the console.

⬇️

Download on-console

No PC required. Pick an item, and the store handles the rest.

🗜️

Auto-extract and place

Files land in the correct folder automatically. Ready to use.

🔗

Multiple sources

Anaconda's own catalog plus the Free60 Store — all in one place.

⚙️

Configurable repo

Change the source URL from the Settings menu on the console.

🎮

Any modded console

RGH, JTAG, or softmod. If it runs Aurora, it runs Anaconda.
